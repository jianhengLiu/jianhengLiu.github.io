{%- comment -%} GitHub star count for one repository. Rendered from _data/github_stars.yml (last weekly sync) so the badge is correct with JavaScript disabled; assets/js/live-metrics.js then tries to refresh it from the GitHub API and rewrites .metric__count in place. If that fails the baked-in number simply stays. Usage: {% include github-stars.html repo="owner/repo" %} {%- endcomment -%} {%- if include.repo -%} {%- assign stars = site.data.github_stars[include.repo] -%} {%- if stars -%} ★{{ stars }} {%- endif -%} {%- endif -%}
